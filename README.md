# Mercado Ventures

Static website for Mercado Ventures Pte. Ltd. No build is required.

The portfolio features UX Marine, Boat Sparky, UX Habitat, Neptune Tech and Casa Mercado. Polska Marine is described within the UX Habitat umbrella. The Casa Mercado feature links to https://casamercado.club/ and UX Habitat links to https://uxhabitat.com/.

Upload the root files and referenced assets folder to the hosting document root, including hidden `.htaccess`, `robots.txt`, `sitemap.xml` and `llms.txt`. See `DEPLOYMENT.txt`. GitHub source updates do not independently confirm production deployment.

The layout uses exact #002FA7 and the approved shield identity. Portfolio images need `height:auto` alongside their width/aspect-ratio styling; preserve this when changing intrinsic image dimensions.
